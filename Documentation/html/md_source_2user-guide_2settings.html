Viewer Settings

HtsViewerSettings 是每个 Viewer 实例独立拥有的外观设置值对象。

1. 读取

HtsViewerSettings settings = viewer.settings();

2. 修改

修改返回的副本本身不会自动改变 Viewer。

例如：

HtsViewerSettings settings = viewer.settings();
settings.DEFAULT_SELECTED_COLOR =
HtsColor4f{1.0f, 0.55f, 0.05f, 1.0f};
settings.DEFAULT_EDGE_LINE_WIDTH = 1.2f;

3. 应用

if (!viewer.applySettings(settings)) {
// settings 无效或应用失败。
}

4. Validation

SDK 提供：

isValidViewerColor(color);
isValidViewerSettings(settings);

建议业务 UI 在提交前先做 Validation。

5. 颜色范围

HtsColor4f 的 RGBA 分量需要位于：

[0.0, 1.0]

并且为有限数值。

6. 当前公开设置

颜色：

  • DEFAULT_COLOR
  • DEFAULT_VERTEX_COLOR
  • DEFAULT_EDGE_COLOR
  • DEFAULT_FACE_COLOR
  • DEFAULT_SELECTED_COLOR
  • DEFAULT_PREVIEW_COLOR
  • DEFAULT_MOUSE_OVER_COLOR
  • SCALE_TEXT_COLOR
  • SCALE_POLYGON_START_COLOR
  • SCALE_POLYGON_END_COLOR
  • DEFAULT_WARNING_COLOR

数值：

  • DEFAULT_TRANSPARENCE
  • DEFAULT_REFRESH_FREQ_IN_MS
  • DEFAULT_EDGE_LINE_WIDTH
  • DEFAULT_MOUSE_OVER_LINE_WIDTH
  • DEFAULT_SELECTED_EDGE_LINE_WIDTH
  • DEFAULT_SELECTED_FACE_OPACITY
  • DEFAULT_SELECTED_VERTEX_POINT_SIZE

7. DEFAULT_TRANSPARENCE

这是兼容型百分比字段：

0 ~ 100
0 = opaque

注意它与 HtsMaterialAppearance::transparency 的 0.0 ~ 1.0 浮点约定不同。

8. INI

加载并应用：

viewer.loadSettings(filePath);

保存当前 Viewer 设置：

viewer.saveSettings(filePath);

公开契约说明 loadSettings() 在成功时以完整设置值应用。

9. 多 Viewer

不要假设 Settings 是全局单例。

viewerA.applySettings(settingsA);
viewerB.applySettings(settingsB);

两个 Viewer 可以拥有不同设置。
