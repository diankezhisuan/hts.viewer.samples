Glossary

Display Data

用于 CAD / Geometry 正式显示的数据契约，主类型为 HtsDisplayMeshData。

Mesh Data

用于 CAE Surface / Volume Mesh 的数据契约，主类型为 HtsMeshDisplayData。

Object ID

业务对象稳定标识。

Topology Tag

Face / Edge / Vertex 等拓扑实体的业务标识。

Selection Target

Viewer 返回给业务层的语义选择目标。

Preview

临时交互显示数据，使用独立 tag 管理。

Overlay

工程标注显示，例如 Boundary / Excitation。

Material Appearance

持久 CAD 对象的颜色、透明度和 PBR 参数。

Display Style

Viewer 级显示模式，例如 EngineeringDefault、TriangleWireframe。

Staged Mesh Update

使用 begin / append / end 组织 Mesh 后一次发布的公开更新流程。

Viewer Demo

用于产品体验、授权和综合能力验证的完整示例应用。

Sample

用于说明某一类 API 用法的最小开发者示例。
