HtsViewerSettings API Reference

HtsViewerSettings 是 Per-Viewer、OSG-free 的公开值对象。

构造后得到 SDK Factory Defaults。

修改副本不会立即改变 Viewer，必须：

viewer.applySettings(settings);

Validation

bool isValidViewerColor(const HtsColor4f& color);
bool isValidViewerSettings(const HtsViewerSettings& value);

Validation 规则包括：

  • 所有 Color 分量为有限数；
  • Color 分量位于 [0,1]；
  • DEFAULT_TRANSPARENCE 位于 [0,100]；
  • Refresh Frequency > 0；
  • Line Width > 0；
  • Selected Face Opacity 位于 [0,1]；
  • Vertex Point Size > 0。
