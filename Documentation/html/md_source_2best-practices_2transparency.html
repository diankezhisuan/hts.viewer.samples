透明显示

Hts Viewer SDK 中存在多个透明度相关公开字段。它们的语义并不完全相同。

1. HtsColor4f::a

RGBA 中的 Alpha：

HtsColor4f{r, g, b, a}

通常：

1.0 = fully opaque
0.0 = fully transparent

具体接口如果另外提供 Transparency / Opacity 字段，应以该接口字段定义为准。

2. HtsMaterialAppearance::transparency

这是 CAD-facing Transparency：

0.0 = opaque
1.0 = fully transparent

它是 setTargetMaterialAppearance() / setObjectsMaterialAppearance() 的权威透明度值。

3. HtsRenderMaterial::opacity

这是 Opacity：

1.0 = opaque
0.0 = transparent

4. Mesh Options

Mesh 包含：

opacity
transparentOpacity

它们都是 Mesh 专用显示参数。

5. Preview

HtsPreviewStyle 使用 color.a 表达 Preview Color Alpha。

6. 不要混淆

业务转换层建议提供明确的命名辅助逻辑：

CAD transparency
Viewer opacity
RGBA alpha

不要在调用现场使用没有语义说明的裸 float。

7. 工程显示建议

半透明 AirBox、介质、Mesh 和 Preview 同时存在时，优先使用 Viewer 已公开的专用 API 与 Display Style。

不要试图从业务层操纵 Viewer 私有深度、Blend 或 Render State。
