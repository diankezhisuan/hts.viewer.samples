Display Data 与 Mesh Data

Hts Viewer SDK 为 CAD/几何显示与 CAE 网格显示提供两套不同的公开数据模型。

1. Display Data

入口：

bool upsertDisplayData(const HtsDisplayMeshData& data);

适合：

  • CAD 模型；
  • 几何对象；
  • Face / Edge / Vertex 拓扑显示；
  • 材质和颜色；
  • 面向业务拓扑的选择。

核心结构：

HtsDisplayMeshData
└── HtsDisplayObjectData
├── HtsDisplayBodyData
├── HtsDisplayFaceData
├── HtsDisplayEdgeData
├── HtsDisplayVertexData
└── HtsImportedMaterialData

2. Mesh Data

入口：

bool upsertMeshData(const HtsMeshDisplayData& data);

适合：

  • Surface Mesh；
  • Volume Mesh；
  • FEM / MLFMM 等离散网格；
  • 按 Part 管理的大规模网格；
  • Mesh 专用显示风格。

核心结构：

HtsMeshDisplayData
└── HtsMeshPartData

3. 不建议混用

如果业务数据本质是 CAD Face / Edge / Vertex，优先使用 Display Data。

如果业务数据本质是求解网格或独立 Mesh Part，优先使用 Mesh Data。

这样可以更自然地使用对应的：

  • 选择；
  • 样式；
  • 可见性；
  • 更新；
  • 统计接口。

4. 两者可以同时存在

典型 CAE 应用可以同时显示：

CAD Model
+
Surface / Volume Mesh
+
Preview
+
Engineering Overlay

它们通过各自公开 API 管理。

本手册只说明这些公开能力之间的业务关系，不披露 Viewer 内部显示层的具体实现。
