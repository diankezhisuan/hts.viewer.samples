Viewer 生命周期

HtsViewerSdk 是 Viewer 的统一公开入口。

1. 构造与所有权

hts::viewer::HtsViewerSdk viewer;
hts::viewer::HtsViewerSdk
定义 HtsViewerSdk.h:20

HtsViewerSdk：

  • 禁止复制；
  • 支持移动；
  • 使用 RAII 管理自身公开对象生命周期。

业务层不需要持有 Viewer 内部对象。

2. 初始化模式

Standalone

viewer.initializeStandalone(x, y, width, height);
hts::viewer::HtsViewerSdk::initializeStandalone
bool initializeStandalone(int x, int y, int width, int height)

适合独立 Viewer 程序或 SDK 最小验证。

Embedded

viewer.initializeEmbedded(x, y, width, height);
hts::viewer::HtsViewerSdk::initializeEmbedded
bool initializeEmbedded(int x, int y, int width, int height)

适合嵌入宿主窗口。

宿主窗口绑定与平台事件转发的完整实现应参考对应 Samples。

3. Frame

viewer.frame();
hts::viewer::HtsViewerSdk::frame
bool frame()

或者：

viewer.frame(simulationTime);

业务程序应根据自己的消息循环持续驱动 Viewer。

4. Pending Frame Work

if (viewer.hasPendingFrameWork()) {
// Viewer 仍有需要后续 frame 推进的公开显示工作。
}
hts::viewer::HtsViewerSdk::hasPendingFrameWork
bool hasPendingFrameWork() const

这个接口用于帮助应用程序判断 Viewer 是否仍需要后续 Frame。

不要根据该接口推断或依赖 SDK 内部具体任务切分方式。

5. Close 状态

if (viewer.shouldClose()) {
// 结束 Viewer loop。
}
hts::viewer::HtsViewerSdk::shouldClose
bool shouldClose() const

6. Resize

viewer.resizeViewport(x, y, width, height);
hts::viewer::HtsViewerSdk::resizeViewport
bool resizeViewport(int x, int y, int width, int height)

窗口尺寸或 framebuffer 尺寸变化时应同步 Viewer。

7. Input

宿主输入通过：

viewer.submitInput(event);
hts::viewer::HtsViewerSdk::submitInput
bool submitInput(const HtsInputEvent &event)

提交。

8. 初始化失败

如果初始化返回 false，应用程序应停止后续显示调用并检查：

  • SDK Runtime 是否完整；
  • 授权状态；
  • 图形运行环境；
  • 日志信息。

具体失败原因以 SDK 对应版本的日志为准。
