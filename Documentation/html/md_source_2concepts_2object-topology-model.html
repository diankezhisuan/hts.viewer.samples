对象与拓扑语义模型

Hts Viewer SDK 的 CAD Display Data 不是单纯的三角形数组。业务程序可以在几何数据之外携带稳定的对象和拓扑标识。

1. 业务层级

Viewer 公开选择语义包括：

Object
Body
Face
Edge
Vertex

相应选择模式由：

enum class HtsSelectionMode
{
Object,
Body,
Face,
Edge,
Vertex
};

定义。

2. 主要标识

公开数据常用以下字段建立业务对应关系：

  • objectId
  • bodyId
  • solidTag
  • faceTag
  • edgeTag
  • vertexTag

3. HtsSelectionTarget

拾取和选择结果通过：

struct HtsSelectionTarget
{
HtsSelectionTargetType type;
std::string objectId;
std::string bodyId;
int faceTag;
int edgeTag;
int vertexTag;
};

表达。

Object Target

需要有效 objectId。

Body Target

需要：

  • objectId
  • bodyId

Face / Edge / Vertex Target

需要有效 objectId 与对应正数 Tag。

SDK 提供：

isValidSelectionTarget(target);
isSameSelectionTarget(lhs, rhs);

用于验证和比较目标。

4. 稳定 ID 的意义

业务系统应尽量保证同一个业务对象在增量更新前后继续使用相同的 objectId 和拓扑 Tag。

这样业务层可以稳定执行：

  • Select；
  • Hide / Show；
  • Style Override；
  • Fly To；
  • 根据 Viewer 选择结果反查业务对象。

5. Tag 不等于数组下标

建议把 faceTag、edgeTag、vertexTag 当作业务语义标识处理，而不是把它们与临时三角形数组下标绑定。

如何生成稳定 Tag 由业务数据系统决定。

6. Body 数据

HtsDisplayBodyData 可以记录：

  • objectId
  • bodyId
  • solidTag
  • Body Kind
  • Bounds
  • Face / Edge / Vertex Tag 集合

用于表达 Object 内部的 Body 语义。

7. 推荐做法

业务层建立自己的映射：

Viewer objectId / topologyTag
↕
Business Entity / CAD Entity

不要让 Viewer 内部实现对象成为业务主键。
