数据生命周期

本章从公开 API 角度说明 Viewer 数据如何进入、更新和移除。

1. Display Object

create DTO
↓
upsertDisplayData()
↓
update with same business identity
↓
removeDisplayObject(s)

clearScene() 用于清除正式场景显示数据。

2. Mesh

完整 Mesh：

HtsMeshDisplayData
↓
upsertMeshData()
↓
upsertMeshPart() / visibility / style
↓
removeMeshPart() / removeMesh()

全部 Mesh：

viewer.clearMeshes();

3. Staged Mesh Update

大 Mesh 可通过：

beginMeshUpdate
↓
appendMeshPart
↓
appendMeshPart
↓
endMeshUpdate

在提交前放弃：

cancelMeshUpdate(meshId);

4. Preview

Preview 使用稳定 tag 管理：

upsertPreview(tag)
↓
setPreviewTransform / setPreviewVisible
↓
removePreview(tag)

全部清除：

clearPreviews();

5. Overlay

Face Overlay 使用业务 key：

showBoundaryFaceOverlay(key)
showExcitationFaceOverlay(key)
↓
removeFaceOverlay(key)

全部清除：

clearFaceOverlays();

Plane Wave Glyph 使用 id 独立管理。

6. 业务建议

业务程序应明确区分：

  • Persistent Model Data；
  • Mesh Result；
  • Temporary Preview；
  • Engineering Annotation。

不要为了临时交互效果反复修改正式业务几何。
