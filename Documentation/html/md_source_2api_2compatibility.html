Compatibility API

当前公开 include 中可能仍包含 HtsViewer.h。

本手册的新项目示例统一以：

#include <HtsViewerSdk.h>
hts::viewer::HtsViewerSdk
HtsViewerSdk.h
hts::viewer::HtsViewerSdk
定义 HtsViewerSdk.h:20

作为正式使用入口。

如果 HtsViewer.h 在某个 SDK Release 中继续发布，应将其视为该版本提供的兼容接口，并以对应 Release Notes 对其支持策略的说明为准。

新业务代码不建议同时混用 HtsViewer 和 HtsViewerSdk 两套入口，以免形成重复生命周期和不清晰的所有权关系。
