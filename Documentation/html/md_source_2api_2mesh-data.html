Geometry Rules

  • partId 必须非空；
  • 同一 Mesh 内唯一；
  • indexed triangle 每三个 index 一个 Triangle；
  • triangle soup 时顶点数是 3 的倍数；
  • indexed edge 每两个 index 一条 Edge；
  • edge soup 时顶点数是 2 的倍数；
  • ID 数量必须和对应元素数量一致；
  • 至少包含 Triangle 或 Edge。
