世界坐标与屏幕坐标

Hts Viewer SDK 提供公开的空间查询接口，业务层无需访问内部 Camera 对象。

1. Screen to World Ray

HtsVec3d origin;
HtsVec3d direction;
if (viewer.screenToWorldRay(x, y, origin, direction)) {
// 使用世界坐标射线进行业务计算。
}

适合：

  • CAD 交互；
  • 自定义吸附；
  • 构造工作平面交点；
  • 自定义测量工具。

2. World to Screen

HtsVec3d screenPoint;
if (viewer.projectWorldToScreen(worldPoint, screenPoint)) {
// screenPoint 为 framebuffer 坐标。
}

公开注释规定其屏幕坐标原点位于左上角。

3. 高 DPI

嵌入 Qt 等 GUI 框架时，需要明确区分：

  • Widget logical coordinates；
  • framebuffer / device pixel coordinates。

Viewer API 的屏幕坐标应和实际传给 Viewer 的 viewport 尺寸保持一致。

具体 DPI 转换方式取决于宿主 UI 框架。
