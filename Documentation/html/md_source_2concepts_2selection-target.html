Selection Target

HtsSelectionTarget 是 Viewer 与业务系统之间传递选择语义的核心公开结构。

1. Target Type

enum class HtsSelectionTargetType
{
None,
Object,
Body,
Face,
Edge,
Vertex
};

2. Target 内容

HtsSelectionTarget target;

根据 target.type 读取对应身份字段。

不要假设所有字段在所有 Target Type 下都有业务意义。

5. 查询式 Pick 与 Selection

Query Pick

viewer.pickTarget(x, y, target);

用于查询屏幕位置下的目标，不改变当前 Selection。

Selection

viewer.selectAt(x, y);

用于修改 Viewer 当前选择状态。

应用程序应根据需求区分二者，避免把纯查询操作错误地转成 Selection。

6. 完整 Selection Set

多选场景使用：

std::vector<HtsSelectionTarget> targets = viewer.selectionTargets();

不要只依赖：

viewer.selectionTarget();

来代表多选集合。
