产品介绍

1. Hts Viewer SDK 是什么

Hts Viewer SDK 是面向 CAD、CAE 与工业三维应用的软件开发工具包。它为 C++ 应用程序提供统一的三维显示、选择交互、显示控制、工程标注和网格可视化能力。

SDK 的设计目标是让业务系统专注于：

  • CAD/CAE 业务数据；
  • 几何与拓扑关系；
  • 网格与求解数据；
  • 用户交互逻辑；

而 Viewer 负责公开 API 所定义的三维显示与交互能力。

2. 适用场景

Hts Viewer SDK 适用于：

  • CAD 建模软件；
  • CAE 前处理软件；
  • 有限元与电磁网格显示；
  • 求解前模型检查；
  • 工程模型浏览器；
  • 工业三维数据审阅工具；
  • 自研几何内核或求解器的可视化前端；
  • 需要嵌入三维视图的 Qt / C++ 桌面软件。

SDK 本身不限定业务系统采用哪一种 CAD Kernel。业务系统只需要把自身数据转换为公开 Display Data 或 Mesh Data。

3. 主要能力

3.1 CAD Display

公开 Display Data 支持 Object、Body、Face、Edge、Vertex 等业务层级，并允许业务系统携带稳定 ID 与拓扑 Tag。

3.2 Mesh Display

独立 Mesh API 支持：

  • Surface / Volume 类型；
  • 多 Part 管理；
  • Shaded、Wireframe、透明面线显示；
  • Part 可见性；
  • Part Selection；
  • Part Style；
  • Mesh Statistics；
  • 分阶段 Mesh Update。

3.3 Semantic Selection

Viewer 可以按 Object、Body、Face、Edge、Vertex 模式选择，并通过 HtsSelectionTarget 返回业务语义。

3.4 Material & Appearance

支持颜色、透明度以及金属度、粗糙度、镜面强度等材质外观参数，并提供工程材质预设。

3.5 Preview

临时建模结果可以使用 Preview API 管理，不需要业务层直接访问 Viewer 内部渲染对象。

3.6 Engineering Overlay

公开 API 提供 Boundary、Excitation 和 Plane Wave 等工程标注能力。

4. 产品优势

统一、独立的公开 API

业务代码通过 HtsViewerSdk 访问 Viewer，不需要依赖内部模块或渲染实现类型。

面向 CAD/CAE 的语义交互

Viewer 的公开选择结果不是通用渲染对象编号，而是业务可识别的 Object / Body / Face / Edge / Vertex 目标。

CAD 与 Mesh 分离

CAD Geometry 与 CAE Mesh 使用不同的数据契约，便于业务系统根据数据性质进行独立更新、显示和管理。

支持增量业务更新

公开 API 提供 Object Upsert、Mesh Part Upsert 和分阶段 Mesh Update，使业务层无需为了局部变化而重新组织全部数据。

工程显示能力完整

Viewer 公开提供 CAD Edge、Triangle Wireframe、AirBox、PBR、Grid、Coordinate System、HUD、Preview、Boundary / Excitation Overlay 和 Plane Wave Glyph 等能力。

5. 关于性能说明

Hts Viewer SDK 面向工业模型交互场景设计，并提供适合大模型应用的增量接口和分阶段提交接口。

本手册不会披露内部渲染算法、缓存结构或私有性能策略。产品的量化性能指标应以对应版本的正式 Benchmark、测试报告或产品规格书为准，不应从接口形式推导具体性能数字。
