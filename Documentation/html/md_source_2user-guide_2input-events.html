Input Events

嵌入宿主窗口时，业务应用通过 HtsInputEvent 向 Viewer 转发输入。

入口：

viewer.submitInput(event);

1. Event Type

支持：

  • MouseMove
  • MouseButtonPress
  • MouseButtonRelease
  • MouseDoubleClick
  • MouseWheel
  • KeyPress
  • KeyRelease
  • Resize
  • Close
  • MouseWarped
  • PenPressure
  • PenOrientation
  • PenProximity
  • TouchBegan
  • TouchMoved
  • TouchEnded
  • Quit

2. Mouse

HtsInputEvent event;
event.type = HtsInputEventType::MouseMove;
event.x = x;
event.y = y;
viewer.submitInput(event);

按钮：

HtsMouseButton::Left
HtsMouseButton::Middle
HtsMouseButton::Right

3. Wheel / Trackpad

HtsScrollMotion：

  • None
  • Left
  • Right
  • Up
  • Down
  • TwoDimensional

二维触控板滚动可以使用：

event.scrollMotion = HtsScrollMotion::TwoDimensional;
event.scrollDeltaX = dx;
event.scrollDeltaY = dy;

4. Keyboard

公开字段：

event.key
event.unmodifiedKey

宿主框架需要把自身 Key Code 转换为 Viewer 使用的输入值。

完整映射建议集中在 Adapter 中，而不要散落在多个 QWidget / Window Handler 中。

5. Pen

公开支持：

  • pressure；
  • tiltX；
  • tiltY；
  • rotation；
  • Pen / Puck / Eraser；
  • proximity enter / leave。

6. Touch

公开字段：

  • touchId
  • touchPhase
  • tapCount
  • x / y

Touch Phase：

  • Began
  • Moved
  • Stationary
  • Ended

7. Resize

虽然 HtsInputEvent 支持 Resize 类型，SDK 同时提供：

resizeViewport(...)

宿主窗口尺寸变化时应按照对应 Sample 的统一方式处理，避免同一次 Resize 被业务层重复提交。

8. DPI

输入 x/y 与 resizeViewport() 使用的 viewport 尺寸必须处于一致的像素坐标体系。

Qt 高 DPI 环境下通常需要关注 devicePixelRatioF()。

9. 推荐 Adapter 结构

Qt / Win32 Event
│
▼
Application Input Adapter
│
▼
HtsInputEvent
│
▼
viewer.submitInput()

Adapter 是业务应用代码，不属于 Viewer SDK 内部实现。
