Authorization API

本章只面向需要在自有产品中集成授权 UI 的开发者。

普通试用用户建议直接使用 Hts Viewer Demo 的授权管理界面。

1. 状态

viewer.isAuthorized();
viewer.checkAuthorization();

2. Machine Code

std::string code = viewer.machineCode();

或者：

viewer.exportMachineCode(filePath);

3. Import License

if (!viewer.importLicense(directoryPath)) {
// 业务 UI 提示导入失败。
}

导入后建议重新：

viewer.checkAuthorization();

4. UI 建议

授权 UI 应至少显示：

  • 模块名称；
  • 当前授权状态；
  • 导出机器码；
  • 导入授权；
  • 结果提示。

真实机器码和授权内容属于敏感产品信息，不建议写入普通业务日志。
