稳定业务标识

稳定 ID 是 CAD/CAE Viewer 接入中最重要的数据契约之一。

1. Object ID

objectId 应：

  • 非空；
  • 在业务生命周期内稳定；
  • 能够反查业务对象；
  • 不依赖临时内存地址。

推荐：

数据库 UUID
业务 GUID
稳定模型对象 ID

不推荐：

pointer address
临时 vector index
本次显示随机编号

2. Body ID

同一个 Object 内存在多个 Body 时，每个 Body 应具有稳定 bodyId。

3. Topology Tag

Face / Edge / Vertex 的 Tag 应能够在当前业务数据版本中稳定定位对应拓扑实体。

4. Mesh ID / Part ID

meshId 表示完整 Mesh Result。

partId 表示该 Mesh 中一个可独立管理的 Part。

同一个 meshId 内 partId 必须唯一。

5. 更新

如果某个 Part 只是颜色改变：

partId should remain unchanged

如果业务含义已经变成新的 Part，才应使用新的 ID。

6. Selection 回写

Viewer 返回：

HtsSelectionTarget

业务系统根据稳定 ID / Tag 查询自己的实体。

不要依赖 Viewer 私有对象指针进行反查。
