# viewer_interaction

演示语义选择和临时预览。Viewer 窗口中可使用鼠标点击选择，按住 `Ctrl` 点击可追加
或取消多个目标；快捷键用于切换选择模式、选择显示和 Preview。

| 按键 | 操作 |
|---|---|
| `1/2/3` | 对象、面、边选择模式 |
| `Ctrl + 左键` | 多选或取消目标 |
| `A/C` | 全选可见、清空选择 |
| `D/F/V` | Dim 开关、适合选择、适合全部 |
| `P/X` | Preview 几何、局部 Preview 坐标轴开关（坐标轴默认隐藏） |
| `S/H` | 输出选择结果、重新打印帮助 |

这里的“对象选择”按拓扑最顶层工作：分别选择单个 Solid、单个 Sheet 或独立 Edge，
不会把包含多个 Solid/Sheet 的整个导入模型一次性高亮。
